# 安装说明 · 醒脑（Adaptive Cognition Engine）

本 skill = 技能文本 ＋ 定时任务。只装文本不装定时，就没有"每天一段"。

## 一、智能体操作清单（照着执行）

1. 把本目录放入宿主智能体的 skills 目录（具体路径按宿主平台的 skill 安装规范）。
2. 初始化用户数据目录 `~/.xingnao/`：把包内 `templates/` 下的 `sent_log.json`（空数组 `[]`）和 `user_prefs.json`（默认偏好）复制过去。已有历史的不要覆盖。运行时状态只读写 `~/.xingnao/`，永不写 skill 目录（市场更新会整体覆盖 skill 目录）。
3. 用宿主平台的定时任务机制建一个每日任务：
   - 任务内容："按本 skill 的 SKILL.md『晨间段子模式』生成今日段子，追加 sent_log.json，并推送给用户"。
   - 定时任务命令里的路径是本机特定的，按实际安装路径重建。
4. 验证：手动触发一次完整流程（选主题→写段子→写 sent_log→推送），确认用户能收到。

## 二、用户决策清单（安装时请用户定，平时随时可改）

| 决策项 | 选项 | 默认 |
|---|---|---|
| 每天几点收 | 任意时间 | 08:40 |
| 一天几段 | 1 段 / 2 段（早晚） | 1 段 |
| 语言风格 | 大白话 / 简洁干练 / 温和娓娓 | 大白话 |
| AI 人设 | 朋友 / 教练 / 陪练 | 朋友 |

改法：直接跟智能体说一句话，如"改成晚上九点发""人设换成教练"，智能体负责改定时任务或记录偏好。

## 三、说明

- 领域自适应：不需要用户画像。段子案例的领域由智能体的上下文和记忆决定，装完即用。
- 卸载：删 skill 前先停掉定时任务，否则任务会继续空跑。
